# Spec Delta

## ADDED Requirements

### Requirement: 按预算拆分时收支分开呈现
Agent SHALL 在呈现按预算拆分的汇总时,把每个预算的收入与支出分开给出。收入(如利息)会落在某个预算下,只给净额会让该预算的支出看起来变少,Agent SHALL NOT 只用净额代表一个预算的花费。

#### Scenario: 某预算下既有支出也有收入
- **WHEN** 按预算拆分的结果显示某个预算下既有支出又有收入
- **THEN** agent 分别给出该预算的收入与支出,不只报告二者的差额

#### Scenario: 存在尚未分配预算的交易
- **WHEN** 汇总结果里有一组标识为尚未分配预算的收支
- **THEN** agent 把它作为独立的一组呈现,并指出这些交易还没有分配预算,不把它并进任何一个预算

### Requirement: 单月预算结构不作年度判断
Agent SHALL 在用户依据单月的预算拆分判断财务结构时,指出单月会被一次性的大额支出主导,结构判断应看更长的时间跨度。

#### Scenario: 用户问这个月的预算结构
- **WHEN** 用户依据某单月按预算拆分的结果判断自己的支出结构
- **THEN** agent 说明单月结果会被该月的一次性大额支出主导,并建议用更长的时间范围来看结构

## MODIFIED Requirements

### Requirement: 分类/来源拆分仅包含有交易的项
Agent SHALL 将 `get_financial_summary` 按分类、按来源或按预算拆分结果中未出现的分类、来源或预算理解为该范围内无收支,而非数据缺失或查询出错。

#### Scenario: 某分类在统计范围内无交易
- **WHEN** 解读 `get_financial_summary` 按分类、按来源或按预算的拆分结果
- **THEN** agent 将结果中未出现的分类、来源或预算理解为"该范围内无收支",不当作数据缺失或查询出错来处理
