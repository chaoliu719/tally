## 3. 过滤生效与重新拉取

- [x] 3.1 点击「应用」时，把过滤条当前值(日期转换为 `YYYY-MM-DD HH:MM:SS`，起始补 `00:00:00`、结束补 `23:59:59`)提交为活跃过滤条件，清空已加载的交易数组与分页游标，回到第 1 页，收起过滤条；验证：设置一个已知会缩小结果集的过滤条件后应用，面板只展示匹配的交易且从第 1 页开始
- [x] 3.2 面板向 `search_transactions` 发起的请求(首次与翻页懒加载)统一带上当前活跃过滤条件中非空的 `source_id`/`category_id`/`start_time`/`end_time`；验证：翻到第 2 页及以后仍只返回符合过滤条件的交易
- [x] 3.3 点击「重置」清空过滤条中的所有输入与活跃过滤条件，重新拉取该账本全部交易；验证：设置过滤后再重置，面板恢复展示未过滤的完整交易列表
- [x] 3.4 选择父分类时不应隐式包含其子分类的交易(与 `search_transactions` 的 `category_id` 精确匹配语义保持一致)；验证：对一个有子分类的父分类应用过滤，归类在子分类下的交易不出现
